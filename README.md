# NSD 공명 색채·잔향 연구소 — 공개 기록 통합판

## 바뀐 화면
- **이용 안내**: 첫 화면
- **48문항 설문**: 캐릭터 등록 시 **공개 체크 1개**만 사용
- **내 기록**: 본인이 등록한 캐릭터만 표시, 수정·삭제 가능
- **공개 기록**: Firebase의 `publicProfiles`에 공개된 모든 캐릭터를 검색하고 **1인 결과를 읽기 전용**으로 열람
- **페어 분석 / 그룹 분석**: 공개 캐릭터 비교 기능 그대로 유지

**기존에 페어·그룹 비교용으로 공개한 캐릭터도 추가 동의나 재응답 없이 공개 기록 탭에서 1인 결과를 열람할 수 있습니다.** 공개되지 않은 캐릭터는 나타나지 않습니다.

## GitHub Pages에 적용하기
1. GitHub 저장소에 있는 기존 `firebase-config.js`를 삭제하거나 덮어쓰지 마세요. 실제 연결 설정이 저장된 파일입니다.
2. 이 ZIP을 풀고 `index.html`, `app.js`, `content.js`, `engine.js`, `style.css`, `배포확인.txt` 등 파일을 **저장소 최상위**에 업로드해 같은 이름 파일을 교체하고 Commit changes를 누르세요.
3. GitHub → Actions에서 배포 성공 확인. 웹 페이지에서 `Ctrl+Shift+R`로 강력 새로고침하세요.
4. `/배포확인.txt`에 접속하면 어떤 수정본이 올라갔는지 확인할 수 있습니다.

## Firebase 설정
- **Firebase 설정값 재입력은 불필요합니다.** `firebase-config.js`를 기존 그대로 사용하세요.
- 이번 버전은 이미 등록된 `isPublic` 값을 사용하므로, Firebase 컬렉션 데이터를 다시 저장하거나 이관할 필요가 없습니다.
- 이전 규칙을 정상 배포했다면 **Firestore 규칙을 수정할 필요도 없습니다.** 이 패키지의 `firestore.rules`는 참고용으로 동봉했습니다.

## 공개 범위
공개 문서에 들어 있는 분석 좌표·상황 선택 코드로 1인 결과를 재구성해 보여줍니다. 비공개 설문 원본 40개 응답은 공개하지 않습니다. 공개 결과를 읽는 사람은 자신의 캐릭터가 아닌 기록을 수정·삭제할 수 없습니다. 등록자에게만 Firebase 쓰기 권한이 주어집니다.

이 업데이트는 사이트 코드만 바꾸며 기존 Firebase의 기록을 삭제하지 않습니다.
