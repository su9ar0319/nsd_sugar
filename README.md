# NSD 공명 색채·잔향 연구소 v0.3

센티넬·가이드 캐릭터용 비공식 창작 콘텐츠. **각자 48문항(1~10점 40개 + 상황 선택 8개)**에 답하고 개인 색채·3단 조향, 2인 페어 분석, 3인 그룹 공명을 확인할 수 있습니다.

## A. GitHub Pages에 바로 올려보기 (서버 없이 체험)

1. GitHub에서 새 저장소를 만들고 이 폴더의 `index.html`, `style.css`, `content.js`, `engine.js`, `app.js`, `firebase-config.js`를 **저장소 최상위 폴더**에 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 선택 후 저장합니다.
3. GitHub Pages 주소로 접속해 설문과 개인·페어·그룹 분석을 시험합니다.
4. `firebase-config.js`가 `null`이면 **로컬 체험 모드**입니다. 이때 다른 사용자 프로필은 자동으로 나타나지 않습니다. 공유용 JSON 파일을 가져오면 비교할 수 있습니다.

> 이 폴더의 `index.html`은 다른 4개 파일을 불러오므로, 파일 하나만 올리면 작동하지 않습니다. 함께 제공한 `NSD_공명연구소_v03_체험판.html`은 별도 파일 없이 열 수 있는 단일 파일 시험판입니다.

## B. 여러 사람이 각자 등록·공개·비교하게 하기 (Firebase 추가)

정식 공개 전 Google/Firebase 이용 약관, 예상 사용량·과금 정책, 개인정보 공개 범위를 확인해 주세요.

1. Firebase 콘솔에서 프로젝트를 만들고 **Web 앱**을 추가합니다.
2. **Authentication → Sign-in method → Anonymous** 공급자를 사용 설정합니다.
3. **Firestore Database**를 만들고 `firestore.rules`의 규칙을 **Rules 탭에 붙여넣어 게시**합니다. 테스트용 전체 허용 규칙을 유지하지 마세요.
4. `firebase-config.js`의 `window.NSD_FIREBASE_CONFIG = null;`을 Firebase 프로젝트 설정에서 제공하는 **웹 앱 구성 객체**로 교체합니다. 이 파일에 Firebase 관리자 비밀키나 서비스 계정 키를 넣으면 안 됩니다.
5. Authentication의 **Authorized domains** 목록에 실제 GitHub Pages 호스트가 필요한지 확인하고 추가합니다.
6. GitHub에 변경을 올린 뒤 페이지를 새로고침합니다. 공개 프로필 목록이 서버에 저장되는지 **두 브라우저**로 시험합니다.

공개에 동의한 캐릭터의 **이름·직군·6축 점수·12개 세부 지표·8개 상황 선택 코드**만 `publicProfiles`에 저장합니다. **원본 40개 응답**은 인증된 해당 브라우저 사용자만 접근할 수 있는 `users/{uid}/records/{id}`에 따로 저장합니다. 공개 동의를 취소하면 공개 문서를 삭제합니다. 문서 내용 자체는 공개 열람 가능한 것으로 취급해 주세요. 권한이 필요한 값(서비스 계정, API 비밀키, 관리자 권한)은 절대 GitHub에 업로드하지 마세요.

**주의: 익명 로그인**은 브라우저 데이터를 지우거나 다른 기기를 사용하면 기존 기록 수정 권한을 잃을 수 있습니다. 로그인/계정 복구가 필요한 정식 서비스에서는 Google 계정 등 영구 인증으로 변경하는 게 좋습니다. 현재 키트는 소규모 팬 커뮤니티 체험용입니다.

## 사용 순서

- `48문항 설문`: 이름/직군 입력 → 1~10점 40개 → 장면 선택 8개 → 저장
- `개인 결과`: 고유색 HEX·3단 조향·장문 해설·선택 흔적 확인
- `페어 분석`: 서로 다른 두 캐릭터를 선택해 A→B / B→A 비교
- `그룹 분석`: 세 사람의 공통점, 상이한 반응, 합성색·향 확인
- `공유용 내보내기`: 다른 브라우저로 **분석값만** 옮길 JSON
- `원본 백업`: 설문 원문 응답까지 포함. **타인에게 전송하지 마세요.**

이전 v0.2의 48문항과는 내용 및 점수 방식이 달라 **이전 결과는 자동으로 마이그레이션하지 않습니다**.

## 결과 분류와 설명

- 색은 360도 Hue, 명도·채도까지 계산하고 24가지 설명 계열을 붙입니다. 고유 HEX는 연속형입니다.
- 탑·하트·베이스는 각각 6계열 × 4노트에서 따로 선택됩니다. 이론상 24³ = 13,824개의 조합이지만 모든 조합이 동등한 확률로 나온다는 뜻은 아닙니다.
- 페어 결과는 **12개 관계 원형 × 8개 관계 자세 = 96개 기본 조합**과 방향별·상황별 해석으로 구성합니다.
- 결과는 캐릭터 해석을 위한 창작 비유입니다. 실제 심리진단, 능력치, 향수 처방, NSD 공식 설정이 아닙니다.

## 테스트할 것

1. 센티넬/가이드 각각 48문항 저장 → 개인 결과/색상/향 표시
2. 공개 체크 해제한 캐릭터가 **다른 브라우저의 검색 목록에 보이지 않는지**
3. 각기 다른 브라우저에서 동시에 페어 선택 → 서로 화면에 영향이 없는지
4. 페어 A/B 순서를 바꿨을 때 방향별 문장이 바뀌는지
5. 그룹 3명 중 중복 선택 시 분석이 표시되지 않는지
6. 모바일 화면·PDF 인쇄 확인

Firebase 설정은 제공하지 않았으므로 **클라우드 저장/동시 사용에 대한 실제 통합 테스트는 아직 수행하지 않았습니다.** 배포 후 작은 인원으로 시험하고 공개하세요.
